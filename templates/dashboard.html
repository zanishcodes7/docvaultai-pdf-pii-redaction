Data Engineering & Document Privacy

Redact sensitive fields before data moves downstream.

DocvaultAI is an end-to-end PDF privacy and data pipeline studio built with Python, Flask, PyMuPDF, Docker, and Floci (local AWS S3 & SQS emulation). Organizations constantly handle PDFs—invoices, onboarding forms, financial statements, legal records, and compliance reports—containing sensitive information like emails, phone numbers, CNIC/national IDs, card/IBAN numbers, and confidential terms. DocvaultAI detects and permanently masks those entities, generates a structured audit breakdown, and tracks pipeline health with automatic fallback to local preview mode when Floci is offline.

01 · WHAT WE DO

Automated PDF PII Redaction

DocvaultAI inspects every page of an uploaded PDF using Python and PyMuPDF (fitz) to locate and permanently redact sensitive patterns—including email addresses, phone/mobile numbers, CNIC and national ID formats, credit card/IBAN numbers, and any custom comma-separated keywords you specify—before files are shared or ingested into downstream workflows.

02 · WHAT THIS WEBSITE IS FOR

Verifiable Privacy & Side-by-Side Review

Designed as a multi-page engineering studio rather than a black-box script, this platform lets you stage files on the Upload page, configure rules and run redaction on the Process page, view original vs. redacted PDFs side by side, inspect masked entity counts and execution latency, export clean PDFs, and review job history in the Audit Log.

03 · CLOUD & WORKER ARCHITECTURE

Floci S3 / SQS With Local Fallback

The Pipeline view monitors local AWS emulation via Floci (port 4566), surfacing configured buckets, queue depth, and modular worker components (worker/consumer.py, worker/db.py, worker/redaction_engine.py, scripts/init_aws.py). Whenever Floci is stopped or unreachable, the app seamlessly falls back to local preview mode so testing and demos stay smooth.

End-to-End Lifecycle

How Data Moves Through DocvaultAI

Each step is separated cleanly so you can upload, configure, redact, audit, and verify infrastructure without clutter.

1. Stage on Upload Select or drag a source PDF and verify file size before moving to processing.
2. Apply Policy & Mask Toggle PII categories (Emails, Phones, CNIC/IDs, Cards/IBAN) and add custom terms.
3. Compare & Export Inspect original and redacted PDFs side by side, check counts, and download outputs.
4. Audit & Monitor Review past runs in the Audit Log and check Floci S3/SQS status in Pipeline.
